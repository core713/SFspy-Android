# SFspy-Android

# This utility is designed for working with packet logs. You can collect packet data without fear of leaking data, as we hide almost everything possible.

# Before we begin, let's configure your file:
### For quick testing, you can select FAST TEST.

**Comment out the lines above without parameters and uncomment the lines with FAST TEST.**

**Name your log file: Name the file in the "OUTPUT_FILE" parameter whatever you want your file to be called.**

**In the PACKAGE parameter, select the package name.**

### Next, let's configure your network:
**Find the "MY_SSID" parameter and add the SSID of your network.**

**In the "MY_USER" and "MY_HOST" parameters, enter your computer name and hostname (not your phone's).**

### Great! Now that you've configured the settings, let's configure your OS:
**Install adb, enable developer mode in your phone's settings, and enable USB debugging.**

### Connect your phone to your PC via a wired connection, enter the command "python3 SFspy-Android.py," and allow the connection.

### Done! You've configured the settings, and the utility is now ready to use. Good luck!
